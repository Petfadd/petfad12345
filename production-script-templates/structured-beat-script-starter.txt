# Structured Beat Script Starter
#
# Reusable for any documentary project. Replace every bracketed value with that
# production's own files, clocks, source ranges, captions and visual direction.
# Do not upload this starter unchanged: placeholders are intentionally invalid until
# you supply real production facts.
#
# Rules
# - Number Beats sequentially: 001, 002, 003 … with no fixed maximum.
# - Keep the original SRT wording, cue references and narration-clock values.
# - Give every picture source an exact uploaded filename and explicit IN/OUT.
# - A sound bite may use one picture file and a different external WAV/audio file.
# - MISSING PICTURE is an explicit labelled review placeholder, never substitute
#   another person's footage.
# - Use JPG, JPEG or PNG only for an uploaded still that is approved for a static hold.
# - Master Timeline is the finished-program clock; Narration Clock stays the original
#   narration/SRT clock. Do not offset original narration cues for a cold open.
#
# Replace this sample Beat with as many narration and sound-bite Beats as your story
# needs. Delete the alternative fields that do not apply before importing.
